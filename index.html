Comportamento

Salvar conversas automaticamente
Mantém chats no armazenamento local.
Foco automático no campo
Volta o cursor para a mensagem depois de responder.

Resposta

Tamanho padrão
Controla o máximo pedido à API. Não representa uma “cota restante”.
Pensamento
Quando o modelo suportar, usa o nível escolhido.
Contexto de chats anteriores
Só usa memória local explicitamente salva, não envia todo o histórico de outros chats.

Modo de programação

As respostas podem priorizar código completo, nomes de arquivos, preview e correções quando o modo programador estiver ligado.

Conversa por voz

Pausa para enviar
Tempo de silêncio antes de mandar sua fala à IA.
Falar respostas
Usa a síntese de voz do próprio navegador.
Resposta econômica
No modo voz, pede respostas curtas para diminuir espera e consumo.

Privacidade da voz

O navegador pode usar um serviço de reconhecimento de fala próprio. Isso é uma limitação da API de voz do navegador; não é necessário adicionar uma biblioteca externa ao arquivo.

Memória local

Esta é uma memória persistente real do aplicativo: os itens ficam no armazenamento local deste navegador e podem ser editados ou apagados. A IA só recebe esses itens quando a opção de contexto estiver ligada.

Memória de projeto

Projetos usam uma camada mais forte: resumo acumulado + índice de arquivos + versões locais. A primeira versão de cada arquivo marcado pela IA fica preservada como ORIGINAL.
